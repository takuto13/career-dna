## タスク1：全8タイプページ WebPage JSON-LD追加

**背景：** タイプページは現在BreadcrumbList・WebApplicationのみ。WebPageスキーマを追加することでGoogle・AI検索での「このページが何についてのページか」の認識が明確になる。AI検索（Perplexity・ChatGPT）からの参照獲得に有効。

**実装内容：**

全8タイプページ（type-strategist.html / type-analyst.html / type-craftsman.html / type-mediator.html / type-challenger.html / type-creator.html / type-guardian.html / type-nurturer.html）それぞれに以下のパターンで追加：

```json
{
  "@context": "https://schema.org",
  "@type": "WebPage",
  "@id": "https://career-dna.jp/type-[タイプスラッグ].html#webpage",
  "name": "[タイプ名]タイプ｜向いてる仕事・転職先・強み診断｜キャリアDNA",
  "description": "[タイプ名]タイプの強み・向いてる仕事・転職エージェント選びをタイプ別に解説。キャリアDNA無料診断で自分のタイプを確認できます。",
  "url": "https://career-dna.jp/type-[タイプスラッグ].html",
  "isPartOf": {
    "@id": "https://career-dna.jp/#website"
  },
  "breadcrumb": {
    "@id": "https://career-dna.jp/type-[タイプスラッグ].html#breadcrumb"
  },
  "inLanguage": "ja"
}
```

| タイプスラッグ | タイプ名 |
|-------------|--------|
| strategist | 戦略家 |
| analyst | 分析者 |
| craftsman | 職人 |
| mediator | 調整役 |
| challenger | 挑戦者 |
| creator | 表現者 |
| guardian | 守護者 |
| nurturer | 育成者 |

**注意：** 既存のBreadcrumbList・WebApplication JSON-LDと重複しないように新しい `<script>` タグとして追加。

## タスク2：index.html HowTo JSON-LD追加（診断プロセスの構造化）

**背景：** 「キャリア診断のやり方」「自己分析の手順」等の検索クエリでHowToスキーマが有効。AI検索での「診断手順は？」という質問への回答にも活用される。

**実装内容：**

index.htmlの既存JSON-LDに追加（新しい `<script>` タグとして）：

{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "AIキャリア診断の使い方（5分・無料・登録不要）",
  "description": "25問の質問に答えるだけで、8タイプのキャリア診断結果と向いてる仕事・転職アドバイスを受け取れます。",
  "totalTime": "PT5M",
  "step": [
    {
      "@type": "HowToStep",
      "name": "ステップ1：診断開始",
      "text": "「キャリア診断をはじめる」ボタンをクリックして診断を開始します。登録・ログイン不要です。",
      "position": 1
    },
    {
      "@type": "HowToStep",
      "name": "ステップ2：25問に回答",
      "text": "仕事への姿勢・強み・価値観に関する25問に正直に回答します。所要時間は約5分です。",
