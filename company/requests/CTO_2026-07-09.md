## タスク1：faq.html 検索機能 + カテゴリ別構成の実装

### Issue #14 オーナー指示内容
> FAQページには検索機能を実装して項目が多くても知りたいことがすぐ見つかるようにして
> カテゴリ名 → FAQピックアップ5問 → もっと見る → CTA → カテゴリ名 → ...

### 実装仕様

#### ① 検索機能（ページ上部に配置）

```html
<div class="faq-search-box">
  <input type="text" id="faq-search" placeholder="FAQを検索する（例：退職理由、エージェント）">
  <button id="faq-search-btn">🔍 検索</button>
</div>
```

- JavaScriptでリアルタイム絞り込み（input イベントで各FAQ `<details>` の `<summary>` と `.faq-answer` テキストを検索）
- マッチしないFAQは `display:none`、マッチしたものだけ表示
- 検索クリア時は全カテゴリ・全FAQを再表示

#### ② 7カテゴリ構成（たくとへのカテゴリ提案・Issue #9対応）

以下の7カテゴリに319問を振り分けて実装する：

| カテゴリ | 主な対象FAQ | おすすめ表示問数 |
|---------|-----------|-------------|
| 1. 診断・自己分析 | Q1〜Q30系（診断の使い方・自己分析法） | 5問ピックアップ |
| 2. 転職準備・計画 | Q31〜Q80系（転職決断・準備・時期・費用） | 5問ピックアップ |
| 3. 書類・面接対策 | Q81〜Q130系（職務経歴書・面接・退職理由） | 5問ピックアップ |
| 4. 転職エージェント・求人 | Q131〜Q180系（エージェント選び・求人票・交渉） | 5問ピックアップ |
| 5. 内定・退職・入社準備 | Q181〜Q240系（内定・退職手続き・入社前準備） | 5問ピックアップ |
| 6. 転職後・職場適応 | Q241〜Q280系（試用期間・職場環境・ストレス） | 5問ピックアップ |
| 7. 就活・キャリア相談 | Q281〜Q319系（就活・スキルアップ・AI時代） | 5問ピックアップ |

#### ③ 各カテゴリの構成（Issue #14 指定フォーマット）

```
カテゴリ見出し（例：「📋 書類・面接対策」）
↓
FAQピックアップ 5問（展開式 <details>/<summary>）
↓
「▼ さらに見る（○○問）」ボタン → 残りのFAQをアコーディオン展開
↓
CTA（jobs.html への誘導ボタン）
↓
次のカテゴリ見出し ...
```

#### ④ CTAの内容（各カテゴリ末尾に設置）

カテゴリ別に内容を変える：
- **診断・自己分析**：「キャリアDNA診断を受ける（無料・5分）→」
- **転職準備・計画**：「あなたのタイプに合う転職時期を確認する →」
- **書類・面接対策**：「タイプ別面接対策を確認する →」
- **転職エージェント・求人**：「タイプ別おすすめエージェントを見る →」
- **内定・退職・入社準備**：「内定後の手順をタイプ別に確認する →」
- **転職後・職場適応**：「転職後の職場適応法をタイプ別に確認する →」
- **就活・キャリア相談**：「今の就活状況をキャリアDNA診断で確認する →」

全CTA遷移先：`jobs.html`（またはタイプ別 `jobs.html?type=XXX`）

## タスク2：全8タイプページ FAQを「3問ピックアップ + もっと見る」に変更

### Issue #14 オーナー指示内容
> その他ページの1部分にFAQを掲載しているページは以下のような構成にして長いスクロールをなくしましょう。
> FAQピックアップ3問 → もっと見る（FAQ遷移）

### 実装仕様

各タイプページ（type-craftsman.html〜type-nurturer.html）のFAQセクション：

```html
<!-- 変更前：全98問を全展開 -->
<!-- 変更後：3問ピックアップ + もっと見るリンク -->

<section class="faq-section">
  <h2>よくある質問（[タイプ名]の転職FAQ）</h2>
  
  <!-- ピックアップ3問（最もアクセスされやすいもの） -->
  <details class="faq-item">
    <summary>Q1: [タイプ名]に向いている仕事は？</summary>
    <div class="faq-answer">...</div>
  </details>
  <details class="faq-item">
    <summary>Q10: [タイプ名]の強みと弱みは？</summary>
    <div class="faq-answer">...</div>
  </details>
  <details class="faq-item">
    <summary>Q20: [タイプ名]におすすめの転職エージェントは？</summary>
    <div class="faq-answer">...</div>
  </details>
  
  <!-- もっと見る → faq.html遷移 -->
  <div class="faq-more-link">
    <a href="/faq.html#[タイプ名カテゴリアンカー]" class="btn btn-secondary">
      全98問のFAQを見る →
    </a>
  </div>
</section>
```

### 各タイプページのピックアップ3問選定基準
- Q1（向いてる仕事・職種） = 最重要SEOキーワード対応
- Q10または近い問（強み・弱み） = 自己分析層への訴求
- Q20または近い問（おすすめエージェント） = 収益導線直結（jobs.html）
