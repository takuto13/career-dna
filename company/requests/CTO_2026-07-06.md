## タスク1【最優先】：faq.html 実装状況の確認・完全化

### 確認・実装内容

現在 faq.html には検索機能と7カテゴリ構成が実装済みです。以下の通り完全性を確認・調整してください。

**確認チェックリスト：**

1. **検索ボックス**：`.faq-search-container` が正常動作しているか確認
   - キーワード入力 → 即時フィルタリング動作するか
   - 検索結果0件時に「見つかりませんでした」等のフィードバックがあるか

2. **7カテゴリの構成**：各カテゴリが以下の順序で配置されているか確認
   ```
   カテゴリタイトル（h2）
   ↓
   FAQピックアップ（最初の5問）※表示状態
   ↓
   もっと見るボタン（残り問数を表示）
   ↓
   残りのFAQ（もっと見るクリックで展開）
   ↓
   カテゴリCTA（jobs.html 誘導ボタン）
   ```

3. **CTAボタン**：各カテゴリの末尾に `.faq-category-cta` が設置されているか
   - 「あなたに合う転職エージェントを確認する →」等のテキストでjobs.htmlへ誘導
   - 7カテゴリすべてにCTAが設置されているか確認

4. **Issue #14追加要件**：「広告の下にFAQを置く」
   - faq.html のページ最上部に広告ユニットがある場合、その下にFAQコンテンツが来るよう確認
   - 現在の配置で問題なければそのまま

### もし未実装の箇所があれば

- カテゴリCTAが一部のカテゴリに未設置の場合 → 全7カテゴリに追加
- もっと見るボタンが5問ではなく別の数の場合 → 5問に調整
- 検索機能に不具合がある場合 → バグ修正

## タスク2：全8タイプページ FAQ表示の確認・完全化

### 確認・実装内容

タイプページの FAQ セクションが以下の構成になっているか確認：

```
【広告ユニット（アフィリエイトカード）】
↓
FAQセクション
  - FAQピックアップ3問（最初の3問を表示）
  - 「FAQをもっと見る →」（faq.html へのリンク）
```

**確認チェックリスト：**

1. 全8タイプページ（type-strategist / type-analyst / type-craftsman / type-mediator / type-challenger / type-creator / type-guardian / type-nurturer）で確認
2. FAQセクションが広告（アフィリエイトカード）の**下**に配置されているか
3. 最初の3問だけが表示され、残りは非表示（またはfaq.htmlへ誘導）になっているか
4. 「FAQをもっと見る →」リンクが faq.html を正しく参照しているか（`/faq.html` または `./faq.html`）

### 修正が必要な場合

- 広告の上にFAQが来ている場合 → FAQセクションを広告の下に移動
- 表示問題数が3問ではない場合 → 3問表示に調整
- 「もっと見る」リンクが壊れている場合 → 修正
