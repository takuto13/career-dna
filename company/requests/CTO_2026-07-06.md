### 1-1. 検索機能の実装

faq.html 上部（ヘッダー直下・広告より前）に**キーワード検索バー**を追加してください。

**実装仕様：**
- プレースホルダーテキスト：「キーワードで検索（例：転職エージェント、自己PR）」
- JavaScript で input イベントをリッスンし、リアルタイムで FAQ 項目を絞り込み
- 絞り込みはカテゴリ名・質問テキスト・回答本文を対象
- ヒット件数ゼロ時は「該当するFAQが見つかりませんでした」を表示
- 検索バーはレスポンシブ対応（スマホ表示で使いやすい横幅）

```javascript
// 実装例（参考）
const searchInput = document.getElementById('faq-search');
searchInput.addEventListener('input', () => {
  const query = searchInput.value.toLowerCase();
  document.querySelectorAll('.faq-item').forEach(item => {
    const text = item.textContent.toLowerCase();
    item.style.display = text.includes(query) ? '' : 'none';
  });
});
```

### 1-2. ページ構成の変更（カテゴリ別ピックアップ構造）

現在の「全FAQアコーディオン一覧」から、以下の構成に変更してください：

```

[広告セクション（既存）]
---
[カテゴリ名：例「転職準備・自己分析」]
  FAQ Q1（アコーディオン展開）
  FAQ Q2（アコーディオン展開）
  FAQ Q3（アコーディオン展開）
  FAQ Q4（アコーディオン展開）

  [もっと見る] ボタン → クリックで当カテゴリの残りFAQを展開（または別ページ）
  [CTA：「今すぐキャリア診断で強みを確認する →」jobs.html へのリンク]
---
[カテゴリ名：例「エージェント活用法」]
```

**ピックアップ選定基準：**

- CTA はすべて jobs.html へ誘導（「このタイプの求人を見る」「キャリア診断を受ける」等）

| 戦略型 | 論理思考を活かした転職・リーダーシップ・年収UP戦略 |
