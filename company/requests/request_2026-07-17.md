### ①【Issue #16】X Developer Portal でAPI申請

**何をするか：** X（Twitter）の自動投稿スクリプトを本番稼働させるためのAPIキーを取得する

**手順：**
1. https://developer.x.com/en/portal/dashboard にアクセス（Xアカウントでログイン）
2. 「Create Project & App」でアプリを新規作成
3. 「App permissions」を「Read and Write」に設定
4. 取得するキー：
   - API Key（Consumer Key）
   - API Secret（Consumer Secret）
   - Access Token
   - Access Token Secret
5. 取得したキーを GitHub → Settings → Secrets → Actions に登録：
   - `TWITTER_API_KEY`
   - `TWITTER_API_SECRET`
   - `TWITTER_ACCESS_TOKEN`
   - `TWITTER_ACCESS_TOKEN_SECRET`

**なぜ急ぐか：** 原稿は2027年1月分まで完成済み。APIさえ取得すれば今日から自動投稿が稼働できる。  
**所要時間：** 約30〜40分
