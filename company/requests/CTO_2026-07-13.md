## タスク3：Issue #16 対応 ― X自動投稿システム技術設計書の作成

### 背景

Issue #16 でたくとがX自動投稿の自動化環境を求めている。  
CEOが全体設計を検討中。CTOは技術実装側の設計書を作成すること。

### 制約ルール（たくとからの指示）

自動投稿システムは以下のルールを遵守するものとする：
- AIっぽい言葉遣いをしない（SNS担当が原稿作成時に注意）
- 絵文字を多用しない（1〜2個程度まで）
- 炎上が予想される言葉を含む原稿を自動投稿しない
- 他社情報・他社名を含む原稿を投稿しない
- 時事ネタを含む原稿は**自動投稿対象外**（手動確認後に投稿）
- 投稿予約時には必ずCEO報告書でたくとに報告する
- ハッシュタグは2〜3個まで
- 140字以内を推奨

### 設計書の作成先

`company/reports/x_auto_post_design_2026-07-13.md`

### 設計書に含めるべき内容

1. システム全体像（GitHub Actions + X API v2）
2. 必要なもの一覧（たくとが実施するもの・CTOが実施するもの）
3. ファイル構成（workflow yaml・投稿スクリプト）
4. 上記ルールをシステムに組み込む方法
5. 想定コスト（X API Free Tierで対応可能か確認）
6. 実装手順（承認後に実行するためのステップ）

**注意: 設計書のみ作成。実際の実装はたくとの承認後に行う。**
