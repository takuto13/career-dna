## 投稿② 2029年10月23日（火）試用期間を意識する

**テーマ：試用期間を意識し始める時期 × タイプ別「本採用に向けて今やること」**

---

配属から3週間。

そろそろ「試用期間」という言葉が頭をよぎり始める頃。

試用期間で評価される基準は「スキル」だけじゃない。
タイプ別に「本採用に向けて今やること」をまとめます。

✅ 戦略家・分析者タイプ
→ 「この人は問題解決できる」と思われることを目指す
→ 小さな改善提案を一つ、上司に相談してみる
→ 報告・連絡・相談のタイミングを意識して増やす

✅ 調整役・育成者タイプ
→ 「この人がいると職場がうまくいく」と思われることを目指す
→ チームの潤滑油になる：感謝・気配り・声かけを継続する
→ 困っている同期を一人サポートすることで信頼を積む

✅ 挑戦者・表現者タイプ
→ 「この人は面白いことをやってくれる」と思われることを目指す
→ 自分なりのアイデアを一つ、形にする（小さくていい）
→ エネルギーの高さと前向きさを周囲に見せ続ける

✅ 職人・守護者タイプ
→ 「この人は任せられる」と思われることを目指す
→ 締切厳守・ミスゼロ・丁寧な仕事を続ける
→ 「この業務だけは自分が一番詳しい」というものを一つ作る

焦らなくていい。3週間でできることは限られている。
でも今の行動が必ず評価につながる。

---

🔹 戦略家・分析者タイプ
→「なぜこのルールがあるのか」を理解しようとする
→ 無駄だと思っても、まずは理由を探してから判断する
→ 合理的でなければ上司に「こうしたほうがいいですか？」と聞いてみる

🔹 調整役・育成者タイプ
→ 職場の雰囲気を読むのが得意。このタイプが一番スムーズに適応できる
→ 先輩の行動を素直に真似ることで自然と馴染める
→ 「空気を乱さない」が強み。でも遠慮しすぎは禁物

🔹 挑戦者・表現者タイプ
→「この慣習、変えたい！」という衝動が出やすい時期
→ まず3ヶ月は観察・理解に徹する（変革は根拠が必要）
→ 新しい視点を持ちながら、まず受け入れる姿勢を見せる

🔹 職人・守護者タイプ
→ ルールには従順に従える強みがある
→ ただし「なんとなく怖くて聞けない」は要注意
→ 疑問は小さいうちに確認する習慣をつける

## 投稿④ 2029年10月25日（木）報連相のタイプ別スタイル

**テーマ：上司への報告・連絡・相談「タイプ別の上手なやり方」**

---

「報連相」が大事とは言われるけど、
タイプによってやり方は全然違います。

あなたに合った報連相スタイルを見つけよう↓

📋 戦略家・分析者タイプの報連相
→「報告は結論から。理由・経緯・対策の順」
→ 要点を箇条書きにしてから話すと伝わりやすい
→ 相談は「自分なりの答えを持って」から持ちかける

📋 調整役・育成者タイプの報連相
→ 報告しやすい雰囲気を作るのが得意。自然体でOK
→「ちょっとよろしいですか」と一声かけるのがうまい
→ 関係構築を優先しすぎて「相談が遅い」に注意

📋 挑戦者・表現者タイプの報連相
→ 直感的に「これ大丈夫ですか？」と言えるのが強み
→ ただし話が長くなりやすい。先に「○分よろしいですか」と伝える
→ 相談を「アイデア共有」の場として活用する

📋 職人・守護者タイプの報連相
→ 慎重なあまり報告が遅くなる傾向がある
→ 問題が小さいうちに「実は…」と伝えることが大事
→「完璧にまとめてから」は禁物。途中報告が正解
