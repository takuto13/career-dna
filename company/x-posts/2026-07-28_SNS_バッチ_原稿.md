## 08/20（水）秋採用第2週・書類選考本格化・タイプ別対策

```
【書類選考を通過するコツ】タイプ別

🧠戦略家 → 「実績×数字」で即読み取れる構成にする
🔬分析者 → 比較・改善プロセスを具体的に書く
🛠職人 → スキル・資格を証拠として前面に出す
🤝調整役 → 「チームで動かした成果」を明記する
🔥挑戦者 → スピード感・行動量を数字で見せる
🎨表現者 → 「なぜこの会社か」を言葉で差別化する
🛡守護者 → 継続性・責任感を具体エピソードで示す
🌱育成者 → 「人を育てた・巻き込んだ経験」を軸にする

タイプを知ると、書き方が変わる。

▶ career-dna.jp

#転職 #AI自己分析 #秋採用 #書類選考
```
