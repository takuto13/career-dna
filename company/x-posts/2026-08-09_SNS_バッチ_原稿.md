## 11/12（水）：「2ヶ月目で差がつくタイプ別学習法」

---

入社2ヶ月目。ここから「差がつく」学習法がタイプで違います。

🔵 戦略家タイプの学習法
→ 業務の「なぜこの仕組みか？」を掘り下げ、全体像を再構築
→ 上司・先輩の意思決定のパターンを観察してロジックを盗む

🔵 分析者タイプの学習法
→ 1日の業務をデータ化（時間・ミス・改善点）して定点観測
→ 「わからないリスト」を毎週更新して潰していく

🟢 調整役タイプの学習法
→ 「この人のここがすごい」を1人1つ見つけて言語化
→ 雑談の中から仕事の知識を拾う＝インフォーマル学習を活かす

🟢 育成者タイプの学習法
→ 誰かに「教える」ことで自分の理解を深める（人に説明できる＝習得）
→ 「ありがとう」と言われた瞬間を記録して強みにつなげる

🟡 挑戦者タイプの学習法
→ 「もっといいやり方があるはず」という視点で業務を見直す
→ 週1回「試してみたこと」を振り返る習慣をつける

🟡 表現者タイプの学習法
→ アイデアをメモしてためる。出し惜しみしないで提案に変える
→ 「自分がワクワクした瞬間」を記録してモチベーションの源を知る

🔴 職人タイプの学習法
→ 同じ業務を毎回「前回より少し良く」を目標にこなす
→ 自分なりの「ベスト手順書」を作り始める

🔴 守護者タイプの学習法
→ マニュアル・ルールを「完全理解」することを2ヶ月目のゴールに
→ 「安定してこなせた業務」のリストを毎週作って自信をチャージ

2ヶ月目の学習は「量」より「タイプに合った質」。

🔴 守護者タイプ

## 11/17（月）：「3ヶ月目に向けた上司との関係構築、タイプ別アプローチ」

---

3ヶ月目に向けて、上司との関係を育てるフェーズに入ります。

タイプ別「上司との関係構築アプローチ」↓

🔵 戦略家タイプ
→ 「3ヶ月後の目標を上司とすり合わせる時間を設けたい」と自ら申し出る
→ 上司の意思決定に「なぜ？」を持って観察し、信頼の根拠を作る

🔵 分析者タイプ
→ 「業務の課題と仮説」を上司に共有して「考えている人」という印象をつくる
→ 報告は「事実→分析→提案」の順で伝えると評価が上がる

🟢 調整役タイプ
→ 1on1や雑談で上司の価値観を聞き、共感を示しながら関係を深める
→ 上司が困っていることに自分から「手伝えることはありますか？」と声をかける

🟢 育成者タイプ
→ 上司の強みを認め、「先輩のここを見習いたい」と伝える
→ 成長を報告することが上司のモチベーションにもなると理解して積極的に共有

🟡 挑戦者タイプ
→ 「こういうことに挑戦したい」を上司に早めに伝える。許可を得てから動く習慣を
→ 上司に承認欲求があることを理解して、成果報告は必ずする

🟡 表現者タイプ
→ 上司との会話で自分のアイデアや感性を少しずつ出す
→ 「面白いことを考える人」という印象が次のチャンスを呼ぶ

🔴 職人タイプ
→ 「確実にこなす仕事ぶり」を3ヶ月継続することで信頼を勝ち取る。余計な言葉より実績
→ 上司への報告は「完了・精度・改善点」の3点セットで簡潔に

🔴 守護者タイプ
→ 「指示を正確に守る」姿勢が最大の信頼構築。ルールを守る人への評価は高い
→ 「わからないことを確認する」行動も信頼につながると覚えておく

3ヶ月目の評価は、2ヶ月目の上司との関係で決まります。
