## 投稿① 2029年10月15日（月）配属2週目スタート

**テーマ：配属2週目スタート・タイプ別「自分の強みを仕事に活かす初動」**

---

配属2週目スタートのみなさんへ。

先週は覚えることで精一杯だったと思います。
でも2週目からは「自分の強みをどう活かすか」を意識し始めるタイミング。

タイプ別の2週目の過ごし方↓

🔷 戦略家・分析者タイプ
→ 業務の全体像をメモにまとめて「なぜこの仕事が必要か」を理解する週
→ 効率化の観察を始める（まだ提案しない）

🔷 調整役・育成者タイプ
→ 先輩一人に「この仕事で大切にしていること」を質問する週
→ 関係構築が最大の強み・まず話しかけることを意識

🔷 挑戦者・表現者タイプ
→ 「もっとこうしたらいい」という気づきをメモする週（実行は3ヶ月後）
→ 早まらず、まず観察と学習に集中

🔷 職人・守護者タイプ
→ 一つの業務を完璧にマスターすることに集中する週
→ 「確実にこなせた仕事」を毎日一つリストアップして自信をつける

## 投稿③ 2029年10月17日（水）同期比較

**テーマ：同期と比べて落ち込む時のタイプ別対処法**

---

「同期はもう仕事できてるのに、自分は…」

配属2週目になると、こんな気持ちが出てきます。
でも比べる相手を間違えているかもしれません。

タイプ別の「同期比較」への向き合い方↓

🔹 戦略家・分析者タイプ
→ 得意：数字で分析するから比較が具体的になる
→ 注意：比較がストレスに変わりやすい
→ 対処：「同期ではなく先週の自分」と比較する習慣をつける

🔹 調整役・育成者タイプ
→ 得意：同期と仲良くなれる・教え合える
→ 注意：「あの人の方が気に入られてる」と思いやすい
→ 対処：自分が「誰かの助けになれた瞬間」を見つけて記録する

🔹 挑戦者・表現者タイプ
→ 得意：自分のペースで突き進める
→ 注意：焦って動きすぎる
→ 対処：「今週のチャレンジ」を一つ決めて集中する

🔹 職人・守護者タイプ
→ 得意：じっくり着実に成長できる
→ 注意：比較で自信を失いやすい
→ 対処：「昨日できなかったことが今日できた」を毎日探す

## 投稿④ 2029年10月18日（木）初めてのミス

**テーマ：初めての業務ミス・タイプ別リカバリーと再発防止策**

---

仕事でミスをしてしまった。

入社して初めてのミスは誰でもあります。
大事なのは「ミスの後の動き方」。

タイプ別のリカバリー法↓

🔸 戦略家・分析者タイプ
→ リカバリー：「なぜミスが起きたか」を5W1Hで分析する
→ 再発防止：チェックリスト化して次から確認する
→ 注意：自己批判を長引かせない（24時間以内に前に進む）

🔸 調整役・育成者タイプ
→ リカバリー：「申し訳ありません」だけでなく「次はこうします」まで伝える
→ 再発防止：同じ立場の同期に「どうやって防いでる？」と聞く
→ 注意：周りの反応を気にしすぎて引きずらない

🔸 挑戦者・表現者タイプ
→ リカバリー：素早く謝って次の行動に集中する
→ 再発防止：「これが経験値になる」と前向きに意味付ける
→ 注意：同じミスを繰り返さないための記録を忘れない

🔸 職人・守護者タイプ
→ リカバリー：丁寧に謝罪して誠実さを見せる
→ 再発防止：手順を見直してマニュアル化する
→ 注意：完璧主義が出すぎて立ち直りが遅くなりやすい
