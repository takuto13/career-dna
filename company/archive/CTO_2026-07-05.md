## 本日のタスク（優先順）

### タスク1：GA4 アフィリエイトクリックイベント計測追加【収益計測・最優先】

**背景：** キャリアDNAの収益はjobs.html上のアフィリエイトCTAボタンのクリックに依存している。現在、GA4でページビューは計測できるが、アフィリエイトCTAボタンの具体的なクリック数・クリック率が計測できていない可能性がある。データなしでは収益最適化ができないため、計測基盤の整備が急務。

**実施内容：**
1. jobs.html の各アフィリエイトCTAボタン（doda・マイナビ・ビズリーチ・リクナビNEXT等）に GA4 カスタムイベント計測コードを追加
   ```javascript
   // 例: ボタンクリック時に発火
   gtag('event', 'affiliate_click', {
     'service_name': 'doda',
     'page_location': window.location.href,
     'button_position': 'jobs_page'
   });
   ```
2. 計測イベント名は `affiliate_click` で統一し、`service_name`（サービス名）・`page_location`（URL）・`button_position`（ボタン位置）をパラメーターとして送信
3. 各タイプページ（type-*.html）のアフィリエイトカードクリックにも同様のイベントを追加
4. GA4の計測IDは既存コードから参照すること（G-CY9DKC6DZ6）

**期待成果：** どのサービスのCTAが最もクリックされているか可視化 → 収益最大化施策の立案が可能に

**注意事項：**
- デザイン・レイアウトの変更は行わない
- JavaScriptのみの追加（HTMLボタン構造は変更しない）
- 既存のGA4計測コードを壊さないこと
