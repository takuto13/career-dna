## 本日のタスク（優先順）

### タスク1：GA4 アフィリエイトCTAクリックイベント計測追加【収益計測・最優先】

**背景：**  
現在 GA4（G-CY9DKC6DZ6）は設置済みだが、アフィリエイトCTAのクリックが計測できていない。どのサービスのCTAが何回クリックされたか分からない状態では収益最適化が不可能。今すぐ追跡を開始する。

**実施内容：**

jobs.html と全8タイプページ（type-*.html）のアフィリエイトリンク（外部リンク）に `gtag('event', ...)` を追加する。

```html
<!-- 各アフィリエイトCTAリンクのonclick例 -->
<a href="https://xxx-affiliate-link" 
   onclick="gtag('event', 'affiliate_click', {
     'event_category': 'affiliate',
     'event_label': 'doda_jobs',
     'page_type': 'jobs'
   });" 
   target="_blank" rel="noopener">doda に無料登録</a>
```

**パラメータ設計：**

| event_label | 対象サービス | page_type |
|-------------|------------|-----------|
| doda_jobs | doda（jobs.html内） | jobs |
| mynabi_jobs | マイナビ転職（jobs.html内） | jobs |
| rikunabi_jobs | リクナビNEXT（jobs.html内） | jobs |
| bizreach_jobs | ビズリーチ（jobs.html内） | jobs |
| doda_type_XXX | doda（タイプページ内） | type |
| mynabi_type_XXX | マイナビ転職（タイプページ内） | type |

**注意事項：**
- 既存のリンクHTML構造・デザインは変更しない（onclickを追加するだけ）
- gtag.jsが既にロードされているか確認してから追加すること
- jobs.htmlと全8タイプページ（type-craftsman, type-strategist, type-mediator, type-challenger, type-analyst, type-creator, type-guardian, type-nurturer）に実施

**期待成果：** GA4で「どのCTAが何回クリックされたか」が可視化される → 収益最適化の判断材料が揃う
