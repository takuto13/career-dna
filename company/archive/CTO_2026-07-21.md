## タスク1：全8タイプページ Article JSON-LD 追加

**目的：** 各タイプ詳細ページをAI検索エンジンが「キャリア専門記事」として参照・引用するよう構造化データを強化する。

**対象ファイル（全8ページ）：**
- `public/type-strategist.html`（戦略家タイプ）
- `public/type-analyst.html`（分析者タイプ）
- `public/type-mediator.html`（調整役タイプ）
- `public/type-nurturer.html`（育成者タイプ）
- `public/type-challenger.html`（挑戦者タイプ）
- `public/type-creator.html`（表現者タイプ）
- `public/type-craftsman.html`（職人タイプ）
- `public/type-guardian.html`（守護者タイプ）

**追加場所：** 各タイプページの `<head>` 内（既存JSON-LDの後）

**追加するJSON-LD（各タイプページ別に調整）：**

```html
<!-- 例：type-strategist.html の場合 -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "戦略家タイプの強み・向いている仕事・転職戦略｜キャリアDNA診断",
  "description": "キャリアDNA診断の「戦略家タイプ」の特徴・強み・弱み・向いている仕事・転職戦略・おすすめエージェントを解説。論理的思考・目標設定・計画立案を強みとするタイプに特化した実践的キャリアガイド。",
  "url": "https://career-dna.jp/type-strategist.html",
  "author": {
    "@type": "Organization",
    "name": "キャリアDNA",
    "url": "https://career-dna.jp"
  },
  "publisher": {
    "@type": "Organization",
    "name": "キャリアDNA",
    "logo": {
      "@type": "ImageObject",
      "url": "https://career-dna.jp/logo.png"
    }
  },
  "datePublished": "2026-05-09",
  "dateModified": "2026-07-21",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://career-dna.jp/type-strategist.html"
  },
  "about": [
    {"@type": "Thing", "name": "戦略家タイプ"},
    {"@type": "Thing", "name": "論理的思考"},
    {"@type": "Thing", "name": "向いている仕事"},
    {"@type": "Thing", "name": "転職戦略"},
    {"@type": "Thing", "name": "キャリア診断"}
  ]
}
</script>
```

**各タイプページのheadline・description・about調整方針：**

| タイプページ | headline（タイトル） | about（主要キーワード） |
|-------------|---------------------|----------------------|
| type-strategist | 戦略家タイプの強み・向いている仕事・転職戦略 | 戦略家・論理的思考・目標設定・計画立案 |
| type-analyst | 分析者タイプの強み・向いている仕事・転職戦略 | 分析者・データ分析・問題解決・論理的判断 |
| type-mediator | 調整役タイプの強み・向いている仕事・転職戦略 | 調整役・調整力・協調性・チームワーク |
| type-nurturer | 育成者タイプの強み・向いている仕事・転職戦略 | 育成者・育成・サポート・人間関係構築 |
| type-challenger | 挑戦者タイプの強み・向いている仕事・転職戦略 | 挑戦者・行動力・チャレンジ精神・変化適応 |
| type-creator | 表現者タイプの強み・向いている仕事・転職戦略 | 表現者・創造性・表現力・ユニークな発想 |
| type-craftsman | 職人タイプの強み・向いている仕事・転職戦略 | 職人・専門性・丁寧さ・品質へのこだわり |
| type-guardian | 守護者タイプの強み・向いている仕事・転職戦略 | 守護者・安定性・責任感・几帳面さ |

**注意事項：**
- MBTIキーワード（INTJ・ENFP等）は絶対に使用しない
- 既存のFAQPage JSON-LDや他の構造化データと重複しないこと
- dateModified は実装日（2026-07-21）に設定
- 各ページで `@id` と `url` を正しいページURLに変更すること
