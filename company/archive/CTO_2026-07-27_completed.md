## タスク1：jobs.html FaqPage JSON-LD追加

### 目的
jobs.html（タイプ別転職エージェント比較ページ）にFAQ構造化データを追加し、Google SERP上でFAQリッチスニペットを獲得する。アフィリエイトクリック率向上に直結。

### 事前確認
jobs.htmlの`<script type="application/ld+json">`ブロックを確認し、すでに `"@type": "FAQPage"` が存在する場合は追加不要（スキップしてタスク2へ）。

### 実装内容（未実装の場合のみ）
jobs.htmlの既存JSON-LDブロックの直後、または`</body>`直前に以下を追加：

```json
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "転職エージェントはどのタイプを選べばいいですか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "あなたのキャリアDNAタイプによって相性の良いエージェントは異なります。戦略家・分析者タイプはハイクラス特化型エージェント、調整役・育成者タイプは面談サポートが手厚い総合型エージェントが向いています。まずは無料のキャリアDNA診断でタイプを確認してから選ぶのがおすすめです。"
      }
    },
    {
      "@type": "Question",
      "name": "転職エージェントに複数登録してもいいですか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "はい、2〜3社の並行登録を推奨します。タイプ別に最適なエージェントは異なるため、総合型1社と専門特化型1社の組み合わせが効果的です。キャリアDNA診断でタイプを把握した上で選ぶと、各社との面談効率が大幅に上がります。"
      }
    },
    {
      "@type": "Question",
      "name": "キャリアDNA診断とエージェント登録はどちらが先ですか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "診断が先です。自分のタイプ（強み・向いてる仕事・弱点）を把握した状態でエージェントに登録すると、自己PRが明確になり、担当者からの求人提案の質が上がります。診断は無料・登録不要・約5分で完了します。"
      }
    }
  ]
}
</script>
```

### 期待成果
- Google SERP上でFAQリッチスニペット表示 → CTR向上
- 「転職エージェント 選び方」「転職エージェント 複数登録」KWでの流入獲得
- jobs.htmlへのオーガニック流入増加 → アフィリエイトCTR向上

## タスク2：全8タイプページ → index.html「再診断」テキストリンク確認・追加

### 目的
全8タイプページに「もう一度診断を受ける」リンクがあるか確認し、なければ追加する。  
タイプページ閲覧後にユーザーが診断ページに戻れる動線を確保 → 再診断・シェアによる流入増。

### 実装方針
1. 各タイプページ（type-strategist.html・type-craftsman.html 等8ページ）を確認
2. `href="index.html"` を持つ「再診断」系のリンクまたはCTAが存在するか確認
3. **存在する場合**：変更不要
4. **存在しない場合**：アフィリエイトCTA直後または最下部に1行のテキストリンクを追加
   - テキスト例：「もう一度診断する → AIキャリア診断はこちら」
   - リンク先：`index.html`
   - スタイルは既存テキストに合わせる（デザイン変更不可）

### 注意事項
- **デザイン・レイアウト変更は不可**（テキストリンク追加のみ）
- デザイン変更が必要と判断した場合は実装せず、報告書にエスカレーション記載
