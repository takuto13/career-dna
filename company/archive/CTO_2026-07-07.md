## タスク1【最優先】：faq.html FAQPage JSON-LD追加

### 目的

Google検索でFeatured Snippetとしてfaq.htmlのQ&Aが直接表示されるよう、`FAQPage` スキーマを実装します。これにより：
- 検索結果がリッチリザルト（展開Q&A）に変化
- CTR（クリック率）が大幅向上（リッチリザルトは通常リザルトより2〜3倍のCTRがある）
- 「転職 よくある質問」「自己分析 やり方」系のKWでの露出強化

### 実装方針

**既存のArticle JSON-LDとは別に**、`<script type="application/ld+json">` ブロックを1つ追加します。

各カテゴリから上位3問を選び、計7カテゴリ × 3問 = **21問分のFAQPageスキーマ**を実装してください。

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "（既存FAQの質問文そのまま）",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "（既存FAQの回答文の最初の200字程度・HTMLタグ除去・プレーンテキスト）"
      }
    },
    ...（21問分）
  ]
}
</script>
```

### 各カテゴリから選ぶ3問の基準

- **KW検索ボリュームが高そうな質問**（「転職のタイミングはいつ？」「退職の伝え方は？」等）
- **答えが簡潔にまとめられる質問**（200字以内で回答できるもの）
- **競合がFAQスキーマを実装していない質問**（差別化に繋がる）

各カテゴリの対象質問は、faq.htmlの既存Q&Aの中から上記基準で自律的に選んでください。

## タスク2：faq.html 内部リンク深化（FAQ回答内の文脈リンク追加）

### 目的

faq.htmlの各カテゴリ内Q&A回答文の中で、タイプ名に言及している箇所に**インラインリンク**を追加し、タイプページへの内部リンク密度を高めます。

### 実装対象

各FAQ回答文の中で「〜タイプの方は」「戦略家タイプ」「分析者タイプ」等のタイプ名が出てくる箇所に、初出のみリンクを追加：

```html
<a href="./type-strategist.html">戦略家タイプ</a>
<a href="./type-analyst.html">分析者タイプ</a>
<a href="./type-craftsman.html">職人タイプ</a>
<a href="./type-mediator.html">調整役タイプ</a>
<a href="./type-challenger.html">挑戦者タイプ</a>
<a href="./type-creator.html">表現者タイプ</a>
<a href="./type-guardian.html">守護者タイプ</a>
<a href="./type-nurturer.html">育成者タイプ</a>
```

**注意：**
- 1ページ内で同じタイプページへのリンクは最大3〜5回（スパムリンク回避）
- リンクスタイルは既存の `<a>` タグのスタイルに準拠
- カテゴリCTAのリンクと重複しないよう注意
