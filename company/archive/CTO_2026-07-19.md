## タスク1：index.html に WebSite JSON-LD + SiteLinksSearchBox 追加

**背景：** WebSiteスキーマをindex.htmlに追加することで、Google検索結果でサイトリンク表示（サイト内の主要ページへのショートカットリンク）が表示される可能性が生まれる。検索CTRの向上に直結。

**実装内容：**

index.htmlの `<head>` 内既存JSON-LDの後に追加（新しい `<script type="application/ld+json">` タグ）：

```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "@id": "https://career-dna.jp/#website",
  "name": "キャリアDNA",
  "url": "https://career-dna.jp",
  "description": "AI搭載の無料キャリア診断。25問・5分・登録不要で8タイプのキャリア診断を実施。転職・就活のための自己分析を即座に行えます。",
  "inLanguage": "ja",
  "publisher": {
    "@type": "Organization",
    "@id": "https://career-dna.jp/#organization"
  },
  "potentialAction": {
    "@type": "SearchAction",
    "target": {
      "@type": "EntryPoint",
      "urlTemplate": "https://career-dna.jp/faq.html?q={search_term_string}"
    },
    "query-input": "required name=search_term_string"
  }
}
```

**注意：** 既存のWebApplication JSON-LDや Organization JSON-LDと重複しないこと。

## タスク2：robots.txt AIクローラー設定の最新化確認

**背景：** 2026年時点でのAI検索クローラー（GPTBot、Claude-Web、PerplexityBot、GoogleExtendedなど）の設定が最新状態かを確認。AI検索からの流入・被参照獲得に必要。

**確認・実装内容：**

現在の `/robots.txt` を確認し、以下のAIクローラーが `Allow` 設定されているか確認。未設定のものがあれば追加：

```
# AIクローラー（AI検索・LLM被参照獲得のため明示的に許可）
User-agent: GPTBot
Allow: /

User-agent: Claude-Web
Allow: /

User-agent: anthropic-ai
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: GoogleExtended
Allow: /

User-agent: CCBot
Allow: /

User-agent: Bytespider
Disallow: /
```

**注意：** 既に設定済みのものは変更不要。`Bytespider`（TikTokのクローラー）はDisallowが一般的。
