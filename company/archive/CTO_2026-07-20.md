## タスク1：faq.html に Article JSON-LD 追加（AI検索参照強化）

**目的：** AI検索エンジン（ChatGPT・Perplexity・Gemini）がfaq.htmlを「専門記事」として参照するよう構造化データを強化する。

**追加場所：** `public/faq.html` の `<head>` 内（既存JSON-LDの後）

**追加するJSON-LD：**

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "転職・就活キャリアDNA 診断FAQ 全319問",
  "description": "キャリアDNA診断に関するよくある質問319問を収録。タイプ別の転職戦略・強み・向いている仕事など、キャリア選択に役立つ情報を提供します。",
  "url": "https://career-dna.jp/faq.html",
  "author": {
    "@type": "Organization",
    "name": "キャリアDNA",
    "url": "https://career-dna.jp"
  },
  "publisher": {
    "@type": "Organization",
    "name": "キャリアDNA",
    "logo": {
      "@type": "ImageObject",
      "url": "https://career-dna.jp/logo.png"
    }
  },
  "datePublished": "2025-01-01",
  "dateModified": "2026-07-04",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://career-dna.jp/faq.html"
  },
  "about": [
    {"@type": "Thing", "name": "キャリア診断"},
    {"@type": "Thing", "name": "転職活動"},
    {"@type": "Thing", "name": "タイプ別強み"},
    {"@type": "Thing", "name": "就職活動"}
  ]
}
</script>
```

**確認ポイント：**
- 既存のFAQPage JSON-LDと重複しないこと
- dateModified は実装日（2026-07-20）に変更して追加
- sitemap.xml の faq.html lastmod も 2026-07-20 に更新

## タスク2：全8タイプページ OGP（og:description）キーワード最適化

**目的：** SNS共有時・AI検索のOGP取得時に、タイプ別キーワードを含んだ説明文が表示されるよう最適化する。

**対象ファイル：**
- `public/type-strategist.html`
- `public/type-analyst.html`
- `public/type-mediator.html`
- `public/type-nurturer.html`
- `public/type-challenger.html`
- `public/type-creator.html`
- `public/type-craftsman.html`
- `public/type-guardian.html`

**現状の問題：** og:description が汎用的すぎて、タイプ別の強みキーワードが含まれていない可能性がある。

**修正方針：** 各タイプページの og:description を以下のフォーマットに統一する。

```
【タイプ名】の強み・向いている仕事・転職戦略をキャリアDNAで解説。[タイプ固有の特徴2〜3キーワード]。無料診断でタイプを確認できます。
```

**各タイプの固有キーワード例：**
- 戦略家：論理的思考・目標設定・計画立案
- 分析者：データ分析・問題解決・論理的判断
- 調整役：調整力・協調性・チームワーク
- 育成者：育成・サポート・人間関係構築
- 挑戦者：行動力・チャレンジ精神・変化への適応
- 表現者：創造性・表現力・ユニークな発想
- 職人：専門性・丁寧さ・品質へのこだわり
- 守護者：安定性・責任感・几帳面さ

**確認ポイント：**
- 120文字以内（SNS最適化）
- MBTIキーワード（INTJ等）は使用しない
- 「キャリアDNA」ブランド名を含める
