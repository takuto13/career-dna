## タスク一覧（優先順）

### タスク1：全8タイプページ BreadcrumbList JSON-LD追加

**対象ファイル**：`public/type-strategist.html`・`type-analyst.html`・`type-craftsman.html`・`type-mediator.html`・`type-challenger.html`・`type-creator.html`・`type-guardian.html`・`type-nurturer.html`（全8ファイル）

**内容**：各タイプページの既存 `<script type="application/ld+json">` ブロック群に、以下の構造のBreadcrumbList JSON-LDを追加する。

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "ホーム",
      "item": "https://career-dna.jp/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "AIキャリア診断",
      "item": "https://career-dna.jp/"
    },
    {
      "@type": "ListItem",
      "position": 3,
      "name": "[タイプ名]の特徴・向いてる仕事・転職",
      "item": "https://career-dna.jp/type-[英語名].html"
    }
  ]
}
```

各タイプのname例：
- 戦略家タイプ → `"戦略家タイプの特徴・向いてる仕事・転職"` / `type-strategist.html`
- 分析者タイプ → `"分析者タイプの特徴・向いてる仕事・転職"` / `type-analyst.html`
- 職人タイプ → `"職人タイプの特徴・向いてる仕事・転職"` / `type-craftsman.html`
- 調整役タイプ → `"調整役タイプの特徴・向いてる仕事・転職"` / `type-mediator.html`
- 挑戦者タイプ → `"挑戦者タイプの特徴・向いてる仕事・転職"` / `type-challenger.html`
- 表現者タイプ → `"表現者タイプの特徴・向いてる仕事・転職"` / `type-creator.html`
- 守護者タイプ → `"守護者タイプの特徴・向いてる仕事・転職"` / `type-guardian.html`
- 育成者タイプ → `"育成者タイプの特徴・向いてる仕事・転職"` / `type-nurturer.html`

**期待効果**：Google検索結果にパンくずリストが表示 → CTR向上 → 検索流入増加

### タスク2：index.html SoftwareApplication JSON-LD追加

**対象ファイル**：`public/index.html`

**内容**：既存の `@graph` JSON-LDブロック（WebSite・Organization・FAQPage等）に `SoftwareApplication` エントリを追加する。

```json
{
  "@type": "SoftwareApplication",
  "name": "キャリアDNA AIキャリア診断",
  "url": "https://career-dna.jp/",
  "description": "25問の質問でAIがあなたの仕事タイプ・強み・適職を分析する無料AIキャリア診断ツール。登録不要・約5分・スマホアプリ不要のブラウザ完結型。",
  "applicationCategory": "BusinessApplication",
  "operatingSystem": "Web",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "JPY"
  },
  "featureList": "AIキャリア診断・8タイプ診断・転職エージェント紹介・登録不要・スマホ対応",
  "screenshot": "https://career-dna.jp/ogp-image.png",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.5",
    "ratingCount": "120",
    "bestRating": "5"
  }
}
```

※ `aggregateRating` のratingCountはGA4実績ベースで判断・実際の数値に合わせる。不明な場合は `aggregateRating` ブロック自体を省略してよい（虚偽データはペナルティリスク）。

**期待効果**：Google検索でアプリとして認識 → 「AI診断ツール」「AIキャリア診断 無料」検索でのリッチカード表示を狙う
