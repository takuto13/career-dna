## タスク1：全8タイプページ間の内部リンク強化

### 目的
各タイプページを孤立させず、補完タイプ・関連タイプへの内部リンクを追加して回遊率・滞在時間・SEO評価を向上させる。

### 実装内容
各タイプページの転職エージェント活用法セクションの下に「関連タイプを見る」リンクブロックを追加する。

**リンク構成（タイプ別）：**

| タイプページ | リンク先1 | リンク先2 |
|---|---|---|
| type-strategist.html（戦略家） | type-analyst.html | type-challenger.html |
| type-analyst.html（分析者） | type-strategist.html | type-craftsman.html |
| type-craftsman.html（職人） | type-analyst.html | type-guardian.html |
| type-mediator.html（調整役） | type-guardian.html | type-nurturer.html |
| type-challenger.html（挑戦者） | type-strategist.html | type-creator.html |
| type-creator.html（表現者） | type-challenger.html | type-mediator.html |
| type-guardian.html（守護者） | type-mediator.html | type-nurturer.html |
| type-nurturer.html（育成者） | type-guardian.html | type-mediator.html |

**HTMLテンプレート（各ページ共通）：**
```html
<div class="related-types" style="margin-top:2rem; padding:1rem; background:#f8f9fa; border-radius:8px;">
  <p style="font-weight:bold; margin-bottom:0.5rem;">▶ 他のタイプも見る</p>
  <a href="./type-XXX.html">〇〇タイプ →</a>
  <a href="./type-YYY.html" style="margin-left:1rem;">〇〇タイプ →</a>
  <a href="./jobs.html" style="margin-left:1rem;">転職サービスを比較する →</a>
</div>
```

### 注意事項
- デザインは簡素なインラインスタイルのみ使用（既存のCSSクラスと競合させない）
- jobs.htmlへのリンクも各ブロックに含めること（CTA強化）
