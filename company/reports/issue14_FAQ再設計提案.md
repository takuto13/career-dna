## 実装方針

### A. faq.html 検索機能（技術案）

**方針：バニラJS・クライアントサイド全文検索**

```javascript
// 実装イメージ
const searchBox = document.querySelector('#faq-search');
const allItems = document.querySelectorAll('.faq-item');

searchBox.addEventListener('input', function() {
  const query = this.value.trim().toLowerCase();
  allItems.forEach(item => {
    const text = item.textContent.toLowerCase();
    item.style.display = text.includes(query) ? '' : 'none';
  });
});
```

- 外部ライブラリ不要・追加コストゼロ
- 現在の319問を対象に全文一致検索
- 検索結果にハイライト表示を追加（任意）

## リスク・注意事項

### リスク1：FAQ STOP ORDER との関係

- 現在、FAQ質問の追加・削除は「FAQ STOP ORDER」が発動中
- 本実装は「FAQ質問内容の変更」ではなく「構成・表示方法の変更」のため、STOP ORDERの対象外と判断
- ただし「ピックアップ5問・3問の選定」はCTOが行うため、たくとの事前確認を推奨

### リスク2：既存SEO影響

- 現在のタイプページは全98問のFAQ本文がHTMLに展開されており、Google等に全文インデックスされている
- 3問ピックアップ形式に変更すると、残り95問のHTML本文が非表示（`display:none` or 別ページ遷移）となる
- **SEOリスク**：現在インデックスされているFAQ本文がクロールされなくなる可能性がある
- **対応策**：タイプページのFAQ縮小は流入データが取れてから実施することを推奨（strategy.md「やらないこと」に該当する可能性あり）
- faq.htmlは全FAQが1ページに残るため、SEO影響は限定的

### リスク3：UI・レイアウト変更の禁止方針

- decisions.md 2026-05-09：「データが取れるまでUI・遷移・見た目の変更は行わない」方針あり
- FAQページの検索機能追加はUI変更に該当する可能性がある
- **判断**：たくとからの直接指示（Issue #14）があるため、本件は方針の例外として扱う
