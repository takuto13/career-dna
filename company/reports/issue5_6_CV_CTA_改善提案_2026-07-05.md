## Issue #5：「CV/CTAの強化施策」への回答

### 現状の問題点（たくとの指摘どおり）

| 問題 | 具体的な状況 |
|------|------------|
| FAQ情報過多でCTAが埋もれている | 各ページのFAQセクションが長く、アフィリエイトCTAへのスクロールが発生する |
| 収益動線が不明確 | 診断完了 → 結果確認 → エージェント登録の流れが直感的でない |
| CTAの露出機会が少ない | 現在のCTAは主にタイプページと jobs.html に限定されている |

---

### 提案1：診断結果ページ（result.html）の収益動線強化

**現状：** 診断結果を表示する result.html は存在するが、エージェント誘導が弱い可能性

**提案内容：**
```
診断完了 → 結果表示（タイプ名・強み説明）
                   ↓
         【提案】「あなたのタイプにおすすめのエージェント3選」を
                 タイプ結果の直下に表示
                   ↓
         doda / リクルートエージェント / マイナビ転職 のアフィリエイトCTA
                   ↓
                 収益発生
```

**収益効果：** 診断完了直後は転職意欲が最も高い瞬間。この瞬間にエージェント誘導すると最高のCVR。

**実装優先度：** ★★★★★（最優先）

---

### 提案2：全ページ共通 スティッキーCTA バー

**提案内容：**  
すべてのページの画面下部に「固定CTA バー」を追加。スクロールしても常に見える位置に収益CTAが表示される。

```
┌─────────────────────────────────────────────┐
│ 🎯 あなたにぴったりのエージェントを無料診断 → │  ← 常に画面下部に表示
└─────────────────────────────────────────────┘
```

**実装コスト：** 小（CSS position:fixed + CTAボタン1個）  
**期待効果：** 全ページでアフィリエイトCTA露出 → クリック率大幅向上

---

### 提案3：faq.html の各カテゴリ末尾に「関連サービスCTA」追加

**提案内容：**  
各FAQカテゴリの最後に、カテゴリ内容に関連したアフィリエイトCTAを追加。

| FAQカテゴリ | 末尾CTA案 |
|-----------|----------|
| 転職エージェント活用 | 「おすすめエージェントを比較する → jobs.html」 |
| 面接対策 | 「面接対策サービスを見る → jobs.html」 |
| 業界・職種別 | 「[業界]専門エージェントを探す → jobs.html」 |

**既存：** カテゴリCTAは一部のカテゴリに既存。未設置カテゴリへの追加が課題。  
**実装コスト：** 小（HTMLのコピー追加）

---

### 提案4：タイプページ（type-*.html）の「エージェント推薦セクション」を診断結果と連動

**提案内容：**  
各タイプページの最上部または診断誘導CTAの直下に「このタイプにおすすめのエージェント3選」を追加。

```
例: 守護者タイプページ (type-guardian.html)
┌──────────────────────────────────────────┐
│ 守護者タイプ（あなた）にぴったりのエージェント │
│ ① レバウェル看護師  → 26,000円/件        │
│ ② マイナビ看護師   → 高単価              │  
│ ③ doda             → 幅広い求人          │
└──────────────────────────────────────────┘
```

**収益効果：** 守護者・育成者タイプは看護師・薬剤師転職高単価案件に直結。1件成約で26,000〜60,000円

## Issue #6：「求人ページのCV向上デザイン案」への回答

### 現状の問題点（たくとの指摘）

- 広告（アフィリエイトCTA）がページ下部に配置されている
- ユーザーがCTAに到達する前に離脱している可能性がある

---

### jobs.html 改善提案

#### 改善案A：サービス比較表を「上部」に移動（最優先）

**現状：** サービス詳細説明 → 比較表 → CTA の順  
**改善案：** 比較表 → サービス詳細 → CTA の順

```
jobs.html 改善後イメージ：

[H1] 転職エージェント比較・キャリアDNAタイプ別おすすめ

[ファーストビュー内]
┌────────────────────────────────────────┐
│ サービス名  | 特徴      | 単価  | CTA    │
│ doda       | 総合大手  | 高    | 登録→  │
│ マイナビ   | 20代向け  | 高    | 登録→  │  ← ここにCTAを上部に配置
│ ビズリーチ | ハイクラス | 最高  | 登録→  │
└────────────────────────────────────────┘
```

**期待効果：** ファーストビューでCTAが目に入るため離脱前のクリックが増加

#### 改善案B：「タイプ別フィルター」ボタンをファーストビューに追加

**提案内容：**
```
「あなたのタイプで絞り込む：」
[戦略家] [分析者] [職人] [調整役] [挑戦者] [表現者] [守護者] [育成者]
```
タイプをクリックすると該当タイプ向けサービスが上部にくる。

**収益効果：** 自分のタイプ向けCTAが目立つことで「自分に関係ある」と感じてクリック率向上

#### 改善案C：「診断まだの方はこちら」誘導をファーストビューに追加

jobs.htmlに来たが診断未実施のユーザーを診断ページへ誘導し、診断後に再訪問させる動線。
```
┌───────────────────────────────────────────┐
│ ✅ 診断済みの方は↓からタイプ別に見てください │
│ ❓ 未診断の方は → 5分で無料AI診断（index.html）│
└───────────────────────────────────────────┘
```
