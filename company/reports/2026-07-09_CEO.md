#### A. 各ページのアフィリエイトCTR期待値（推定）

| ページ | 役割 | CTR期待値 | 現状の課題 |
|-------|------|----------|-----------|
| **index.html**（診断トップ） | 診断開始 | ★☆☆☆ 低（0〜2%） | 診断前ページのためCTA配置不適 |
| **result.html**（診断結果） | タイプ判定・最初のCTA | ★★★★ 最高（5〜15%） | 診断直後が最高の感情的動機付け |
| **type-XXX.html**（タイプ詳細 × 8） | 詳細情報 + アフィリエイトカード | ★★★☆ 中〜高（3〜8%） | FAQが長すぎてCTAが埋もれている |

**最重要インサイト：**
- **result.html が最高CVR地点**（診断直後の感情ピーク）→ここのCTA強化が最高ROI
- **type-XXX.html の問題点**：FAQが90問以上続いてアフィリエイトカードが埋もれている。Issue #14の修正（FAQ短縮・広告を上位表示）で 3〜8% → 5〜12% に改善見込み
- **faq.html の改善余地**：Issue #14の7カテゴリCTA設置で 1〜3% → 3〜6% に改善見込み

#### B. GA4で今すぐ確認すべき項目（優先順）

**① イベント・クリック計測の確認（最重要）**
```
GA4 → レポート → エンゲージメント → イベント
「click」イベントのうち outbound:true のものを確認
```
→ まずアフィリエイトリンクのクリックが計測されているか確認してください

**② ページ別エンゲージメント**
```
GA4 → レポート → エンゲージメント → ページとスクリーン
確認項目：ページビュー数・平均エンゲージメント時間・イベント数
```

**③ ファネル分析（最重要）**
```
GA4 → 探索 → ファネル探索
ステップ設定：
  1. page_view（index.html）
  2. page_view（result.html）
  3. page_view（type-XXX.html）
  4. page_view（jobs.html）
  5. click（outbound）
```
→ 各ページ間の離脱率・コンバージョン率が数値で確認できます

**④ 流入経路**
```
GA4 → レポート → ライフサイクル → 集客 → トラフィック獲得
Organic Search / Direct / Referral の割合確認
```
