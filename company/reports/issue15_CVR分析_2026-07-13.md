# Issue #15 対応 ― 全ページCVR分析・GA4参照項目

**作成日**: 2026-07-13  
**作成者**: AI CEO  
**対応Issue**: #15「全ページCVの確認」

---

## 目的

最終目標 = アフィリエイト広告のクリック率（CTR）向上。  
各ページのアフィリエイトCTAを評価し、現状のCVR期待値とGA4で追うべき指標を示す。

---

## 各ページのCVR期待値分析

### 1. index.html（診断ページ）

| 項目 | 内容 |
|------|------|
| メインCVアクション | 診断開始ボタンのクリック |
| アフィリエイト直接貢献 | なし（中間ページ） |
| 期待コンバージョン率 | 診断開始率 30〜60%（ランディング効率） |
| 収益への貢献 | 間接（result.html → jobs.html への送客起点） |
| 優先度 | 中（流入獲得が先決） |

**現状の問題点**: 流入数が少ないためサンプルが取れていない状態。SEO流入増加が優先。

---

### 2. result.html（診断結果ページ）

| 項目 | 内容 |
|------|------|
| メインCVアクション | 「このタイプに合う求人を見る →」ボタン → jobs.html 遷移 |
| アフィリエイト直接貢献 | 中（jobs.html への最重要導線） |
| 期待CTR | 5〜15%（現状：フォールド下配置のため低め） |
| フォールド上CTA | ❌ 未設置（改善余地あり） |
| GA4計測 | ✅ `result_to_jobs_click` 実装済み |

**現状の問題点**:
- CTAが1本のみ・フォールド下
- 診断完了直後のユーザーが行動する前に離脱している可能性

**改善ポテンシャル**: フォールド上CTAを追加できれば CTR 5〜15% → 15〜30% 改善見込み（たくと承認後実施）

---

### 3. jobs.html（エージェント比較・求人ページ）

| 項目 | 内容 |
|------|------|
| メインCVアクション | 各転職エージェントのアフィリエイトリンクをクリック |
| アフィリエイト直接貢献 | **最高**（直接収益に直結） |
| 期待CTR | 10〜25%（転職意欲の高いユーザーが流入するため高め） |
| エージェントリンク本数 | 要確認（複数配置されているか） |
| GA4計測 | `affiliate_click` 実装状況を要確認 |

**現状の問題点**:
- result.html → jobs.html への遷移率が低い可能性（result.htmlのCTAが1本のため）
- jobs.html到達後のクリック率は不明（計測イベント要確認）

**収益インパクト**: jobs.htmlへの流入を2倍にできれば収益も2倍になる最重要ページ

---

### 4. type-*.html（タイプ別詳細ページ・8ページ）

| 項目 | 内容 |
|------|------|
| メインCVアクション | アフィリエイトカード（3枚）クリック |
| アフィリエイト直接貢献 | 中（SEO流入からの直接収益化） |
| 期待CTR | 3〜10%（情報コンテンツページ） |
| アフィリエイトカード配置 | 3枚（上中下） |
| GA4計測 | `type_page_affiliate_click` 要確認 |

**現状の問題点**:
- SEO流入が少ないためサンプルが取れていない
- タイプ別にどのエージェントが選ばれているか不明

**改善ポテンシャル**: SEO流入増加後に「タイプ×エージェント」マッチングを最適化することで CTR 向上

---

### 5. faq.html（FAQページ）

| 項目 | 内容 |
|------|------|
| メインCVアクション | 「診断を始める」CTAボタン or 内部リンク |
| アフィリエイト直接貢献 | 低（情報収集ページ） |
| 期待CTR | 2〜5%（SEO流入の情報収集ユーザーが中心） |
| GA4計測 | CTA計測の実装状況を要確認 |

**現状の問題点**:
- FAQページのCTAが十分機能しているか不明
- 「情報を読む → 診断する → エージェント登録」の導線が明確か不明

## CVR改善の優先順位

| 優先度 | ページ | 施策 | 期待効果 | 承認要否 |
|--------|--------|------|---------|---------|
| 1位 | jobs.html | GA4計測確認・リンク動作確認 | 収益計測の精度向上 | 不要 |
| 2位 | result.html | フォールド上CTAの追加 | CTR +10〜20%見込み | **たくと承認要** |
| 3位 | type-*.html | GA4タイプ別クリック計測追加 | データ収集 | 不要 |
| 4位 | index.html | SEO流入増加（CTO担当） | 全体流入向上 | 不要 |
| 5位 | faq.html | CTA効果測定 | データ収集 | 不要 |

## GA4で見るべき項目（たくと向け）

### 毎日チェックすべき項目

| GA4メニュー | 確認項目 | 期待値 |
|------------|---------|--------|
| レポート → エンゲージメント → イベント | `result_to_jobs_click` の発生数 | 毎日確認 |
| レポート → エンゲージメント → イベント | `affiliate_click` の発生数 | 毎日確認 |
| レポート → エンゲージメント → ページとスクリーン | 各ページのセッション数 | 毎日確認 |

### 週次チェックすべき項目

| GA4メニュー | 確認項目 | 意味 |
|------------|---------|------|
| 探索 → ファネル探索 | index.html → result.html → jobs.html の遷移率 | 全体コンバージョンファネル |
| レポート → エンゲージメント → イベント | `career_type` パラメータ別クリック数 | タイプ別人気・CTR差異 |
| レポート → 集客 → トラフィック獲得 | 流入元別セッション数（オーガニック/SNS） | 施策効果確認 |
| レポート → エンゲージメント → ページとスクリーン | 直帰率（高いページが改善対象） | ページ品質評価 |

### result.html のCVR計算方法

```
result.html セッション数 ÷ result_to_jobs_click 発生数 = CVR
（例: 100セッション ÷ 10クリック = 10% CTR）
```

### jobs.html のCTR計算方法

```
jobs.html セッション数 ÷ affiliate_click 発生数 = CTR
（例: 50セッション ÷ 10クリック = 20% CTR）
```

## たくとへの回答まとめ

**Q: 今のページでどれくらいクリックの期待率があるか？**

| ページ | 現状期待CTR | 理由 |
|--------|-----------|------|
| result.html → jobs.html | 5〜15% | フォールド下のCTA1本 |
| jobs.html → エージェント | 10〜25% | 転職意欲高いユーザー層 |
| type-*.html → エージェント | 3〜10% | 情報収集ユーザー混在 |
| faq.html → 診断 | 2〜5% | 情報収集メインページ |

**重要**: 現状は流入数が少なくサンプルが取れていないため、上記は業界標準値に基づく推計。  
GA4データが蓄積されてから実測値で最適化するフェーズへ移行予定。

**Q: GA4とGoogleアナリティクスでどの項目を参照すればよいか？**

→ 上記「GA4で見るべき項目」参照。特に以下の2つのイベントを毎日チェックしてください：
1. `result_to_jobs_click`（診断結果 → 求人ページへの遷移数）
2. `affiliate_click`（アフィリエイトリンクのクリック数）
